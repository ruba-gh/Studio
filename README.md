# شركاء ستوديو ربى

بوابة عربية لإدارة المسوّقين والإحالات وعمولات ستوديو ربى. رابط المسوّق يفتح واتساب برسالة جاهزة فيها كوده.

## التشغيل

يتطلب المشروع Node.js 22.13 أو أحدث.

```sh
npm ci
npm run build
```

التطبيق مبني لتشغيله على OpenAI Sites مع Cloudflare D1 وتسجيل دخول مستقل لكل حساب. ملفات ترحيل قاعدة البيانات موجودة في `drizzle/` وتُطبّق بالترتيب. يحتاج التطبيق إلى نطاق مهيّأ على Sites يسمح لزوار روابط الإحالة بالوصول إلى `/r/<CODE>` دون تسجيل دخول. بوابة الإدارة ولوحات المسوّقين تتحقق من جلسات الدخول والصلاحيات على الخادم.

## تهيئة الإدارة

1. اضبطي قيمة سرية عشوائية لمتغير التشغيل `STUDIO_SETUP_KEY` من إعدادات الاستضافة.
2. استخدمي رمز التهيئة مرة واحدة في شاشة الإعداد الأولى واختاري كلمة المرور. اسم دخول الإدارة هو `admin`. احذفي المتغير من الاستضافة بعد اكتمال التهيئة.
3. أدخلي رقم واتساب ستوديو ربى واختاري تاريخ أول دورة صرف من الإعدادات.
4. أضيفي اسم كل مسوّق وكوده وكلمة مروره الأولية ونسبة العمولة المتفق عليها. الكود هو اسم دخوله، ويقدر يغيّر كلمة مروره من الإعدادات. انسخي رابط الإحالة من قائمة المسوّقين.

## الإحالات والتحويلات

- تسجل الإدارة طلب العميل باستخدام الكود الوارد في واتساب. عند استلام دفعة، حدّثي **إجمالي المبلغ المستلم حتى الآن** في الإحالة. تُضاف العمولة على الزيادة تلقائيًا، حتى بعد صرف عمولة دفعة سابقة.
- يختار المسوّق برق أو STC أو حوالة بنكية ويضيف بيانات التحويل من حسابه.
- تُراجع الأرصدة كل ١٤ يومًا بتوقيت الرياض. يترحل الرصيد إلى الدورة التالية إذا كان أقل من ١٠٠ ريال.
- تنفّذ الإدارة الحوالة من تطبيق التحويل ثم تحفظ مرجعها في اللوحة. تُربط العمولات المصروفة بالحوالة وتظهر في سجل المسوّق.
